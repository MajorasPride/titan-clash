# v8.2.1 "App" (Nov 6, 2026)

Titan Clash can now be played from a website link and installed as an app on phone and PC. Planned with MajorasPride on Nov 6. No fight, titan or control code changed, and nothing was removed.

## New
- **Website:** once GitHub Pages is on, the game plays at https://majoraspride.github.io/titan-clash/ (the `index.html` at the top of the repo sends the link to `game/titan-clash.html`). The sandbox is at `/titan-clash/sandbox/titan-clash-sandbox.html`.
- **Install as an app:** Android/PC Chrome shows "Install" (or menu > Add to Home screen). iPhone: Safari > Share > Add to Home Screen. Opens from its own icon, full screen.
- **Landscape:** the installed app opens in landscape on Android. iPhone can't lock it, so the existing "TURN YOUR PHONE SIDEWAYS" screen now adds a tip to turn off Rotation Lock.
- **Plays offline** after the first load, and still picks up new versions as soon as there's internet.
- **App icon:** original neon mech head with kaiju claw marks over a neon skyline (`icons/icon.svg`, exported to PNGs).

## Files
- `manifest.webmanifest`: app name, icon, full screen, landscape.
- `sw.js`: offline helper. Only runs from the website, so double-clicking `titan-clash.html` works the same as before. Bump `CACHE` in it if the list of core files changes.
- `icons/`: icon.svg plus 512, 192, 180 (iPhone) and 64 (tab) PNGs.
- `titan-clash.html`: a few app tags in `<head>` and the iPhone tip on the rotate screen.
- Repo top: `index.html` (link to the game) and `.nojekyll` (GitHub Pages serves files as they are).
