# Titan Clash

A 3D mech vs kaiju brawler for phone and PC, made by MajorasPride with Claude.

**Play it:** https://majoraspride.github.io/titan-clash/ (install it as an app from there: Chrome > Install, or iPhone Safari > Share > Add to Home Screen).

| Folder | What it is | How to play |
|---|---|---|
| `game/` | The real game (now v8.3.1, "New VALOR" + bug fixes) | Download the folder, double-click `titan-clash.html` |
| `sandbox/` | The training ground: new moves get tested here first | Download `titan-clash-sandbox.html` (one file), double-click it |

**The rule:** new mechanics go into the sandbox first. Only what MajorasPride OKs moves into the game. Nothing is ever deleted: every version stays in this repo's history.

- Plan, ideas, bugs and build log: the "Titan Clash Game Plan" Google Doc.
- New chat with Claude: read `game/README-NEXT-CHAT.md` and `sandbox/SANDBOX.md` first.
- Old versions and archives from before this repo (v7.3 zip, old titans, old maps) are in MajorasPride's Google Drive.
